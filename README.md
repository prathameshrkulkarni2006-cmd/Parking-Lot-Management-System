Parking Lot Management System

 DSA Mini Project

### Project Description
The Parking Lot Management System is a C++ console-based application that manages vehicle parking, vehicle exits, parking slots, and waiting vehicles.

Objectives
- Manage a parking lot with five parking slots.
- Park vehicles and assign available slots.
- Maintain a waiting queue when the parking lot is full.
- Automatically assign a freed slot to the next waiting vehicle.
- Search vehicles and display parking status.

 Data Structures Used
1. **Array:** Tracks the availability of parking slots.
2. **Singly Linked List:** Stores details of parked vehicles.
3. **Queue using Linked List:** Maintains waiting vehicles using FIFO (First In, First Out).

 Features
- Park a vehicle
- Vehicle exit
- Display parking slot status
- Display parked vehicles
- Display waiting queue
- Search for a vehicle
- Display parking summary

Technologies Used
- Programming Language: C++
- Concepts: Classes, Pointers, Dynamic Memory Allocation
- Data Structures: Array, Linked List, Queue

 How to Run
1. Download or clone this repository.
2. Compile `main.cpp` using a C++ compiler.
3. Run the generated executable.

Example compilation command:

`g++ main.cpp -o parking`

Run on Windows:

`parking.exe`

### Conclusion
This project demonstrates the practical application of arrays, linked lists, and queues to manage vehicle parking efficiently.
